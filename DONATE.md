## Where the money goes · 用途

Claude Remote has no running costs beyond the developer's time. Tips go toward:

- code-signing certificates for Windows and macOS (Apple Developer $99/year) so the
  "unknown developer" warnings disappear for every user
  （Windows 与 macOS 的代码签名证书，去掉所有用户首次打开时的安全拦截）
- test servers across Linux distributions to keep the setup wizard reliable
  （多种 Linux 发行版的测试服务器，保证配置向导可靠）

No donation is ever required to use any feature. 所有功能永久免费，捐赠完全自愿。
