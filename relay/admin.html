怎么用

给一个人开通

  1. 在「令牌」页点 新建令牌，填上名字，生成后把令牌复制给他
  2. 他在电脑上打开 Claude 远程助手 → 设置 → 远程控制：中转地址填 ，访问令牌填你给的，点「保存并连接」
  3. 他点「添加手机」，用手机相机扫二维码，两边核对 4 位数字即可

常见操作

  1. 停用某人：令牌页 → 编辑 → 勾「停用」。他的电脑马上断开
  2. 令牌泄露了：编辑 → 换新令牌，旧的立即失效
  3. 有人传文件太慢：电脑页给他「加额度」（只对今天有效），或在规则页提高每天全速额度
  4. 换管理密钥：在服务器上运行 crrelay admin reset，旧链接作废
